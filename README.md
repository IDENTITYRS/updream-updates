# 字字动画 UPdream 插件
版本发布与自动更新仓库。公开下载，激活后使用。
## 下载
请在 [最新发布版](https://github.com/IDENTITYRS/updream-updates/releases/latest) 下载名称以 `updream-` 开头、以 `-full.zip` 结尾的完整安装包（压缩包内为中文插件目录）。请勿下载 GitHub 自动生成的 Source code 压缩包。
## 首次安装或升级
- 新用户：把完整插件目录放进字字动画的 `_internal/plugins/video_plugins/`，重启后选择 UPdream 插件。
- 已有用户：完全退出字字动画，把包内程序覆盖到原插件目录。保留原目录名，不能删除整个目录或新套一层目录。
- 必须保留 `.libtv-license.json`、`.libtv-accounts/`、`.libtv-state/`、`.libtv-recovered/` 和宿主 `user_resources` 中的插件配置。
- 早期版本需手动覆盖安装一次 V1.0.0；版本编号从 V1.0.0 重新开始。
## 以后怎样更新
设置页点击“检查更新”，发现新版后点击更新。下载及签名校验完成后，保存作品、等待任务结束并完全退出字字动画；更新助手自动安装，弹窗通知完成后再手动打开。
更新保留原电脑、原 Windows 用户下的激活、账号、参数及任务记录，不改变授权到期时间。平台登录自然过期仍需重新登录。
更新包采用独立 RSA 发布签名和 SHA-256 校验。发布附件不包含用户账号、激活记录、浏览器资料或私钥。
